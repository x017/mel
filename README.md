# mel

A simple, beautiful screen locker written in C.

**mel** is a lightweight screen locker built around a simple idea: locking your screen should feel clean, quiet, and intentional. No unnecessary complexity, just a minimal interface that does its job.

## Features

- Minimal, aesthetically focused interface
- Written in C
- Simple screen-locking experience

## Installation

Clone the repository:

```bash
git clone <repository-url>
cd mel
```

Build the project using the provided build system.

```bash
make
```

Run the resulting executable according to your system's setup.

## Usage

Launch `mel` to lock your screen.

```bash
./mel
```

The exact launch command and configuration depend on how the project is built and installed.

## Built With

- **C** — implementation
- **Claude** — AI-assisted development

## Philosophy

Keep it simple. Keep it beautiful. Keep it out of the way.

`mel` is a small personal project exploring the intersection of low-level programming and minimal desktop design.
